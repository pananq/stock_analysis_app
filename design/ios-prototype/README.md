# 股海罗盘 iOS 页面交付设计

这是一个以 iPhone 15（390 × 844 pt）为基准的可点击高保真页面原型。

## 信息架构

1. **日报**：最新 AI 分析日报、自选异动、市场温度与今日关注。
2. **自选**：跨 A 股、港股、美股的个人关注列表，支持添加股票。
3. **市场**：展示主要指数与分时趋势。
4. **我的**：个人资料、日报提醒、推送设置和 PRO 订阅。

## 可体验流程

- 4 个底部 Tab 切换
- 日报摘要 → 完整日报
- 自选 → 添加股票 → 加入自选反馈
- 我的 → 订阅方案 → App Store 确认提示
- 分组、市场筛选和通知开关

## 视觉与交互原则

- 深墨绿建立稳定、专业的投研品牌感，珊瑚红突出关键决策和上涨信号。
- 遵循中国市场“红涨绿跌”，同时通过标签和背景色避免只依赖颜色传达状态。
- 主要操作置于拇指热区；添加股票和订阅采用 iOS Bottom Sheet。
- 日报先给结论，再提供证据与观察清单，降低阅读负担。
- 所有分析页保留“不构成投资建议”提示。

## 本地预览

直接打开 `index.html`，或在本目录启动任意静态文件服务器。
